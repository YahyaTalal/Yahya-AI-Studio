========================================================================
             Yahya AI Studio - Startup & Shutdown Guide
========================================================================

Follow these simple steps to run and stop the application:

------------------------------------------------------------------------
1. How to Start the Application
------------------------------------------------------------------------
- Double-click the file named:
  "START Yahya AI Studio.bat"

What it does:
- Opens a new window starting the Python FastAPI backend on port 8000.
- Opens a second window starting the React frontend on port 5173.
- Automatically opens your default web browser to:
  http://localhost:5173

------------------------------------------------------------------------
2. How to Stop the Application
------------------------------------------------------------------------
- Double-click the file named:
  "STOP Yahya AI Studio.bat"

What it does:
- Scans for any active processes running on ports 8000 and 5173.
- Safely closes only the backend and frontend servers of this application.
- Does not affect any of your other Python or Node.js projects.

------------------------------------------------------------------------
Enjoy creating automated News and Health videos!
